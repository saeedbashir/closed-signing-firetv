# Published caption tracks and manifests

Copies of what is served from R2 for the two full-length Scottish Parliament
titles, kept here because the working copies lived in a temporary directory that
the operating system purged. Two of these files cannot be regenerated by running
a command:

- `sp-fmqs-bsl-2026-09-17-full/captions/simplified.en.vtt` — the simplified track,
  written by hand from the Official Report (405 cues). Its manifest entry carries
  `generatedBy` and `reviewed: false`, and the player badges it.
- The two `verbatim.en.vtt` files *can* be regenerated — `stm run` with
  `official_report:` set re-fetches the Report and re-aligns — but word timings
  from the recogniser vary by a few hundred milliseconds between machines, so a
  rerun moves cue boundaries. These are the tracks that were checked on device.

The caption text is the Scottish Parliament's Official Report, used under the
Scottish Parliament Copyright Licence with the attribution each manifest carries
(`CONTENT-LICENCES.md`). The manifests are the published form, with absolute
URLs; the renditions they point to live on R2 and are not copied here.

To republish a track after editing it:

```sh
aws s3 cp catalogue/published/<id>/captions/<file> s3://closed-signing/titles/<id>/captions/<file> \
  --profile cloudflare-r2 --endpoint-url "$R2" --region auto
```
